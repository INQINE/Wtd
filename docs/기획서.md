## 2. 세계관 & 스토리 (초안)

### 2.1 배경
- 왁타버스에 정체불명의 **"밈 오염"** 이 퍼진다. 오염된 밈은 캐릭터의 그림자를 복제해 **섀도우(흑화체)** 를 만든다.
- 섀도우는 원본 캐릭터의 능력과 성격을 비틀어 가진 채 왁타버스 각 지역(이세돌 숙소, 고멤 사무실, 아카데미 등)을 습격한다.
- 플레이어는 왁엔터의 신입 **매니저**. 멤버들을 지휘해 섀도우를 막고 오염의 근원을 찾는다.

### 2.2 이 설정을 쓰는 이유
- **적도 왁타버스 캐릭터로 만들 수 있다.** 아군 버전과 흑화 버전이 같은 캐릭터라서 리소스를 재활용할 수 있다 (색 반전, 보라색 오라 같은 필터만 씌우면 됨).
- 보스전이 곧 "흑화한 아무개 구출전"이 되고, 클리어하면 그 캐릭터를 얻는 흐름이 자연스럽다.

### 2.3 챕터 구성 예시 `[확인]`
| 챕터 | 무대 | 메인 보스 | 클리어 보상 |
|---|---|---|---|
| 프롤로그 | 왁엔터 사옥 | 왁두 무리 | 튜토리얼 멤버 지급 |
| 1장 | 고멤 사무실 | 흑화 고멤 (클래식) | 해당 고멤 |
| 2장 | 고멤 아카데미 | 흑화 아카데미생 | 해당 멤버 |
| 3장 | 이세돌 숙소 | 흑화 이세돌 멤버 | 해당 멤버 |
| 4장 | 왁물원 | 흑화 이세돌 2인 | |
| 최종장 | 밈의 근원 | **흑화 우왁굳 / 거대 왁두** | 엔딩 |

> 스토리 연출은 명일방주처럼 **배경 + 스탠딩 일러 + 대사창** 의 비주얼노벨 형식. 대사는 JSON 스크립트로 관리한다.

## 3. 전투 시스템 (핵심)

명일방주 전투 규칙을 거의 그대로 가져온다.

### 3.1 맵
- **격자 타일맵** (보통 9×6 ~ 13×8칸).
- 타일 종류:

| 타일 | 설명 |
|---|---|
| 지상 (Ground) | 근접 멤버 배치 가능, 적 이동 경로 |
| 고지대 (High) | 원거리 멤버 배치 가능, 적은 못 지나감 |
| 배치 불가 지상 | 적은 지나가지만 배치는 안 됨 |
| 벽 / 장애물 | 아무도 못 지나감 |
| 진입점 (빨강) | 적 스폰 위치 |
| 방어점 (파랑) | 적이 여기 도달하면 방송 체력 -1 |
| 특수 타일 (확장) | 구멍(낙사), 독 장판, 가속 장판, 회복 장판 등 |

- 시점: **위에서 비스듬히 내려다보는 2.5D 느낌**. 1차 버전은 2D 탑다운에 기울어진 타일을 그려서 흉내 내고, 나중에 필요하면 3D로 바꾼다.

### 3.2 배치 흐름
1. 화면 아래 **배치 덱** 에서 멤버 카드를 끌어 타일에 놓는다.
2. 놓은 뒤 **방향(상하좌우)** 을 드래그로 정한다. 방향에 따라 공격 범위가 회전한다.
3. 배치하면 코스트가 빠진다. 코스트는 **초당 1씩** 자동 충전 (시작 코스트는 스테이지마다 다름, 보통 10).
4. 멤버를 **퇴각** 시키면 코스트 50%를 돌려받고, **재배치 대기시간** 이 흐른다.
5. 한 번에 배치할 수 있는 인원 제한 (보통 8명).

### 3.3 저지 (Block)
- 근접 멤버는 **저지 수** 만큼 적을 멈춰 세운다. 저지된 적은 그 멤버를 공격한다.
- 저지 수를 넘는 적은 그냥 지나간다.
- 원거리 멤버는 저지 수 0 (고지대에 배치).

### 3.4 공격 & 데미지 공식
| 종류 | 공식 |
|---|---|
| 물리 | `max(공격력 − 방어력, 공격력 × 0.05)` |
| 마법 | `max(공격력 × (1 − 마법저항/100), 공격력 × 0.05)` |
| 트루 | `공격력` (방어 무시) |
| 회복 | `공격력` 만큼 체력 회복 |

- 공격 간격: `실제 간격 = 기본 간격 × 100 / 공격속도`
- 타겟 우선순위: 기본은 **방어점에 가장 가까운 적**. 비행 우선, 체력 낮은 적 우선 같은 특성은 멤버별로 따로 붙인다.

### 3.5 스킬
- 멤버마다 스킬 1~3개 가운데 하나를 골라 출전.
- **SP 회복 방식** 3가지:
  - 자동 회복 (초당 1)
  - 공격 회복 (공격할 때마다 +1)
  - 피격 회복 (맞을 때마다 +1)
- **발동 방식**: 자동 / 수동 (SP가 차면 멤버를 눌러 발동)
- 스킬 유형: 지속형 (n초 동안 버프), 즉발형, 충전형 (여러 번 쌓기), 패시브

### 3.6 편의 기능
- 일시정지 (일시정지 중에도 배치 가능, 명일방주와 같음)
- 1배속 / 2배속
- 멤버 터치 → 공격 범위·스탯·스킬 정보 표시
- (확장) 자동 지휘: 한 번 클리어한 스테이지는 내 조작을 녹화해서 재생

### 3.7 평가
| 별 | 조건 |
|---|---|
| ★★★ | 적이 한 명도 방어점에 도달하지 않음 |
| ★★ | 방송 체력이 남은 채로 클리어 |
| ★ | 방송 체력 1로 간신히 클리어 (선택) |

### 6.1 일반 몹 (왁두 계열) — 제안
| 이름(안) | 명일방주 대응 | 특징 |
|---|---|---|

| 왁두 궁수 | 석궁병 | 원거리 물리 |
| 왁두 술사 | 캐스터 | 원거리 마법 |
| 철갑 왁두 | 방패병 | 방어력 매우 높음 → 마법으로 잡아야 함 |
| 날개 왁두 | 드론 | 비행, 저지 불가 |
| 폭탄 왁두 | 자폭병 | 저지되면 폭발 |
| 투명 왁두 | 은신 유닛 | 특정 멤버만 탐지 |
| 왁두 돌격대 | 돌격병 | 빠르게 질주 |

> 왁두 대신 다른 밈 캐릭터(팬덤 마스코트 등)를 쓰고 싶으면 알려줘 `[확인]`

### 6.2 엘리트 / 보스 (흑화 캐릭터)
- 아군 멤버와 같은 캐릭터를 흑화 버전으로 쓴다 (팔레트를 바꾸고 보라색 오라를 씌움).
- 보스마다 **고유 기믹** 을 하나씩 둔다. 예시:
  - 흑화 고세구: 맵의 멤버를 무작위로 순간이동시킴
  - 흑화 릴파: 맵 전체에 고음 파동 → 일정 시간마다 전체 마법 피해
  - 흑화 우왁굳: 페이즈 2에서 거대 왁두로 변신, 왁두를 계속 소환

### 6.3 적 스탯 항목
`HP, 공격력, 방어력, 마법저항, 이동속도, 공격 간격, 사거리, 무게(밀치기 저항), 방송 체력 피해량(일반 1 / 보스 2~3), 특수 능력`

## 8. 기타 시스템

### 8.1 오디션 (가챠)
- 명일방주 확률 그대로: ★6 2% / ★5 8% / ★4 50% / ★3 40%
- 천장: 50회 이후부터 ★6 확률 +2%씩 증가
- 혼자 하는 게임이니까 **"전원 해금 모드"** 토글을 둔다 `[확인]`
- 연출: 모집 공고 → 지원서 봉투가 열리면서 레어도 색깔로 빛남

### 8.2 왁엔터 사옥 (기반시설)
- 1차에는 빼고, 나중에 간단한 방치형으로 넣는다.
- 방 종류: 제작실(경험치 아이템 생산), 무역소(후원금 생산), 숙소(텐션 회복), 응접실
- 멤버 배치 시너지 (예: 이세돌 멤버끼리 같은 방에 넣으면 효율 증가)

### 8.3 메인 화면
- 명일방주처럼 **왼쪽에 비서 멤버 스탠딩 일러**, **오른쪽에 메뉴 버튼**
- 메뉴: 작전 / 편성 / 멤버 / 오디션 / 사옥 / 상점 / 임무 / 설정
- 비서를 터치하면 대사가 나온다 (보이스가 있으면 재생)

### 8.4 편성
- 분대 4개 × 최대 12명
- 서포트 유닛(친구 멤버)은 혼자 하는 게임이라 빼거나, "게스트 멤버" 로 대체

## 9. 기술 설계

### 9.1 추천 스택
| 영역 | 선택 | 이유 |
|---|---|---|
| 언어 | **TypeScript** | 타입 덕분에 큰 데이터 테이블에서 실수가 줄어듦 |
| 게임 엔진 | **Phaser 3** | 2D 웹 게임 엔진의 사실상 표준, 모바일 터치 지원이 좋음 |
| 빌드 | **Vite** | 빠르고 설정이 간단함 |
| UI (메뉴) | Phaser 안에서 직접 그리거나 HTML/CSS 오버레이 | 메뉴는 HTML이 편함 |
| 저장 | IndexedDB (localForage) | 브라우저 로컬 저장 |
| 배포 | PWA → 폰에서 "홈 화면에 추가" 하면 앱처럼 실행 | 앱스토어 없이 PC/모바일 모두 지원 |
| (선택) 앱 포장 | Capacitor (안드로이드 APK), Tauri (PC exe) | 진짜 앱 파일이 필요할 때 |

**왜 Unity/Godot이 아니라 웹인가?**
- 폰과 PC 모두 브라우저만 있으면 돌아가서 별도 빌드가 필요 없다.
- 이 저장소 안에서 코드를 바로 짜고 테스트할 수 있다 (자동 브라우저 테스트 가능).
- Godot도 좋은 선택이지만 에디터 작업이 필요해서 코드만으로 진행하기에는 웹이 더 편하다. `[확인]`

## 10. 아트 & 사운드 리소스 목록

캐릭터 디자인은 기존 디자인을 쓰기로 했으니까, **이미지 파일을 어디서 구할지** 가 제일 큰 숙제다.

### 10.1 캐릭터 1명당 필요한 것
| 리소스 | 용도 | 크기(권장) | 필수 여부 |
|---|---|---|---|
| 아이콘 (얼굴) | 배치 덱, 목록 | 256×256 | **필수** |
| SD (치비) 이미지 | 전투 맵 위 유닛 | 256×256, 배경 투명 PNG | **필수** |
| 스탠딩 일러스트 | 상세 화면, 메인 화면, 스토리 | 세로 2048px 정도 | 권장 |
| SD 애니메이션 | 대기/공격/피격/사망 | 스프라이트 시트 또는 Spine | 선택 |
| 2각성 일러스트 | 2각성 보상 | | 선택 |
| 보이스 | 배치/스킬/선택 대사 | | 선택 |

> **애니메이션 없이 시작하는 방법**: SD 이미지 한 장에 코드로 통통 튀기, 기울이기, 번쩍임 효과를 줘서 공격 모션을 흉내 낸다. 처음에는 이걸로 충분하고 나중에 바꿔 끼우면 된다.
> **이미지가 아예 없을 때**: 처음에는 동그라미 + 이름 첫 글자 + 클래스 색으로 된 임시 그래픽으로 개발하고, 이미지가 준비되면 교체한다.

### 10.2 그 외 그래픽
- 맵 타일 (지상/고지대/벽/진입점/방어점) — 직접 만들거나 무료 에셋 사용

- UI: 버튼, 패널, 클래스 아이콘 8종, 레어도 별, 재화 아이콘
- 배경: 메인 화면, 스토리 배경 몇 장
- 이펙트: 타격, 힐, 마법탄, 스킬 발동

### 10.3 사운드
- BGM: 메인 화면, 전투(일반/보스), 오디션, 스토리 → 이세돌·왁타버스 노래나 인스트 음원 `[확인]`

## 부록 A. 공격 범위 표기법

공격 범위는 격자 문자열로 정의한다. `O` = 본인 위치, `X` = 공격 가능 칸. 오른쪽을 바라보는 상태가 기준이고, 방향을 바꾸면 회전시킨다.

```
가드 (근접 1칸)     스나이퍼 (기본)      캐스터 (기본)       메딕 (기본)
```
