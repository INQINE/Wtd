# SD 디자인 가이드 (명일방주식 치비 변환 규칙)

캐릭터 사진이나 일러스트를 올리면, 이 규칙에 따라 **명일방주식 SD(전투용 치비)** 로 바꿔서 게임에 넣는다.

> 방식: 이미지 생성 AI가 그림을 새로 그리는 게 아니라, 사진에서 **특징을 뽑아 사양(SDSpec)으로 기록**하고 코드가 그 사양대로 부위별 SD를 그린다.
> 장점: 모든 캐릭터의 비율과 화풍이 통일되고, 관절 애니메이션(대기·공격)이 자동으로 붙고, 색이나 소품을 숫자 하나로 고칠 수 있다.

---

## 1. 명일방주 SD 스타일 분석

| 항목 | 명일방주 SD의 특징 | 이 게임에서 적용한 값 |
|---|---|---|
| 등신 | 약 2.5~3등신. 머리가 크지만 다리는 가늘고 길쭉한 편 | 키 226 중 머리 지름 약 95 (≈2.4등신), 다리 62 |
| 시점 | 정면이 아니라 **3/4 측면** (몸이 진행 방향을 향함) | 오른쪽을 보는 3/4 측면, 왼쪽은 좌우 반전 |
| 얼굴 | 얼굴 아래쪽에 눈이 위치, 턱이 진행 방향으로 살짝 나옴 | 먼 쪽 눈은 작게, 턱 오른쪽으로 치우침 |
| 눈 | 세로로 긴 눈, 위쪽은 어둡고 아래쪽은 밝은 홍채, 큰 하이라이트 1개 + 작은 하이라이트 1개, 굵은 윗속눈썹 | 동일 (눈 모양 4종: round / sharp / sleepy / smile) |
| 머리카락 | 끝이 뾰족한 **덩어리(클럼프)** 단위, 앞머리가 눈썹을 덮음, 머리 둘레의 밝은 띠(천사의 고리) | 앞머리 3종 + 뒷머리 7종, 하이라이트 띠 |
| 외곽선 | 검정이 아니라 **채움색을 어둡게 한 색**의 얇은 선 | 채움색 RGB × 0.25~0.3 |
| 채색 | 셀 채색 (명암 1단계), 채도가 약간 낮은 팔레트 + 포인트 색 1개 | 그림자 1단계, 포인트 색(accent)으로 끈·리본·장식 통일 |
| 의상 | 테크웨어 재킷, 코트, 끈과 벨트, 소속 마크 | 의상 7종 (hoodie, jacket, uniform, dress, coat, suit, armor) |
| 무기 | 몸만큼 크게, 실루엣으로 클래스가 바로 보임 | 무기 13종, 클래스별 기본 무기 |
| 애니메이션 | Spine 뼈대 애니메이션. 대기(숨쉬기·머리카락 흔들림), 공격(예비 동작 → 타격 → 복귀) | 부위별 리그로 같은 원리 구현 (아래 4장) |
| 그림자 | 발밑 타원 그림자 | 동일 |

### 부위 구성 (명일방주 Spine과 같은 분리 방식)
```
뒷머리 ─ 다리 ─ [상체: 뒤쪽 팔 ─ 몸통 ─ 머리 ─ 앞쪽 팔 + 무기]
```

## 2. 사진 → 사양 변환 순서

1. 사진을 올린다 (전신이면 가장 좋고, 상반신만 있어도 됨). 어느 멤버인지 같이 알려주면 됨.
2. 내가 사진에서 아래 항목을 뽑는다.

| 순서 | 볼 곳 | 사양 항목 |
|---|---|---|
| ① | 머리색, 브릿지/투톤 | `hair.color`, `hair.streak` |
| ② | 머리 길이와 묶은 형태 | `hair.style` (short, messy, bob, long, twintail, ponytail, sidetail) |
| ③ | 앞머리 모양 | `hair.bangs` (straight=일자, swept=옆으로, split=가르마), `ahoge` |
| ④ | 눈 색, 눈매 | `eyes.color`, `eyes.shape` |
| ⑤ | 표정 | `mouth` (smile, neutral, open, cat=ω) |
| ⑥ | 의상 종류와 색 3~4개 | `outfit.style`, `main`(겉옷), `inner`(셔츠), `accent`(포인트), `bottom`(하의) |
| ⑦ | 다리와 신발 | `legs.style` (tights, bare, pants, socks), `color`, `shoes` |
| ⑧ | 머리 장식, 귀, 뿔, 꼬리 | `accessories` (cat_ears, fox_ears, bunny_ears, horns, halo, ribbon, hairpin, flower, headphones, glasses, beret, crown, antenna, tail, wings) |
| ⑨ | 클래스에 어울리는 무기 | `weapon.type`, `color`, `accent` |

3. `src/data/sdSpecs.ts`에 사양을 기록한다.
4. 타이틀 → **SD 도감** 에서 결과를 확인한다 (대기·공격 모션 재생).
5. 마음에 안 드는 부분은 말해주면 고친다. 예: "머리 더 길게", "리본 빨간색으로".

### 사양 예시
```ts
lilpa: {
  hair: { color: 0x2e3a87, style: 'long', bangs: 'straight' },
  eyes: { color: 0x7aa7ff, shape: 'round' },
  mouth: 'open',
  outfit: { style: 'dress', main: 0x24306e, inner: 0xe8ecff, accent: 0x7aa7ff, bottom: 0x24306e },
  legs: { style: 'tights', color: 0x161a33, shoes: 0x12142a },
  weapon: { type: 'mic', color: 0xd9dee8, accent: 0x7aa7ff },
  accessories: [{ type: 'ribbon', color: 0x7aa7ff }],
},
```

## 3. 클래스별 기본 무기와 공격 모션

| 클래스 | 기본 무기 | 공격 모션 |
|---|---|---|
| 뱅가드 | spear (창) | 찌르기 |
| 가드 | sword (검) | 휘두르기 |
| 디펜더 | shield (방패) | 방패 밀치기 |
| 스나이퍼 | crossbow (석궁) / gun / bow | 사격 반동 |
| 캐스터 | staff (지팡이) / mic / book | 들어올려 시전 |
| 메딕 | staff / syringe | 시전 / 휘두르기 |
| 서포터 | book | 시전 |
| 스페셜리스트 | sword | 휘두르기 |

캐릭터 특징에 맞으면 기본 무기 대신 다른 무기를 써도 됨 (예: 이세돌 멤버는 마이크, 도파민 박사는 주사기).

## 4. 애니메이션 규칙

| 상태 | 움직임 |
|---|---|
| 대기 | 상체 숨쉬기 (2.4초 주기, 위아래 1.2px + 세로 늘어남 0.8%), 머리 기울기, 뒷머리가 한 박자 늦게 흔들림, 팔 미세 흔들림 |
| 휘두르기 | 0.09초 들어올림 → 0.08초 내려침 (상체 앞으로 기울임) → 0.25초 복귀 |
| 찌르기 | 뒤로 당김 → 앞으로 찌름 (팔이 앞으로 12px) → 복귀 |
| 사격 | 0.04초 반동 → 복귀 |
| 시전 | 0.14초 무기를 들어올림 → 잠시 유지 → 복귀 |
| 피격 | 0.07초 붉은 틴트 |

## 5. 한계와 앞으로

- 코드로 그리는 방식이라 **원본 일러스트의 세밀한 디테일**(복잡한 무늬, 특수한 의상 형태)은 단순화된다. 사양에 없는 특징이 있으면 부위를 새로 추가할 수 있다 (예: 특정 모자, 고유 무기).
- 직접 그린 SD 이미지나 Spine 데이터가 생기면, 리그 대신 그 이미지를 쓰도록 바꿀 수 있다.
- 흑화 버전(적)은 같은 사양에 어두운 팔레트와 보라색 오라를 씌워서 만들 예정.
